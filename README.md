# posle_cherty_media

Публичное хранилище иллюстраций канала **«После черты»**.

Здесь лежат только картинки. Тексты, концепция и решения — в закрытом репозитории [`posle_cherty`](https://github.com/MaksZakharov/posle_cherty). Файлы отсюда вставляются в статьи Дзена прямыми ссылками:

```
https://raw.githubusercontent.com/MaksZakharov/posle_cherty_media/main/<путь>/<файл>
```

Имена файлов — латиницей (как в `dvortsovye_media`), чтобы raw-ссылки были стабильными.

## Структура

```
пробы/                         пробные обложки до выбора стиля
  style1_cinematic.jpg         кинокадр
  style2_magazine.jpg          журнальная иллюстрация
  style3_caricature.jpg        карикатура
Статьи/                        (позже) кадры по слотам контент-плана
```
